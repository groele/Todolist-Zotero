# v11.0.3 详细审计

日期：2026-10-09。检查基线：v11.0.2；本轮修复版本：v11.0.3。

## 结论

仍存在实际问题。本轮复现并修复了多窗口覆盖、保存结果误报、模板导入与类型丢失、统计与特殊 ID 异常、消息来源校验、设置页异步失败和默认设置恢复等缺陷。

82 项自动化测试通过，25 个 JavaScript 文件通过语法检查，XPI 构建及 ZIP 完整性检查通过。此结论覆盖源码、模拟原生存储及 DOM 测试，不能替代安装后的真实 Zotero 操作验证。

## 已确认并修复的缺陷

| 优先级 | 问题与复现证据 | 修复 |
| --- | --- | --- |
| 高 | 两个窗口同时新增标签或模板，磁盘中只剩第二个窗口的条目；搜索历史也采用整数组覆盖 | 改为在原生写入队列内对最新数据执行增删命令；同步所有窗口缓存；写入失败保留原状态 |
| 高 | A 窗口打开编辑框；B 修改截止日期并新增子任务；A 只改标题后保存，仍会覆盖 B 的改动 | 编辑框保留初始表单快照，仅提交用户实际改变的字段 |
| 高 | 无关页面发送 `TODOLIST_STORAGE_SET`，模拟主窗口会接受并清空任务 | 主窗口校验消息来源，只接受插件工作区；前端也拒绝无关发送者的数据消息 |
| 中 | 任务已经落盘，分类或最终渲染失败仍提示保存失败；导入与清空后的重新读取也可能误报提交失败 | 分开记录持久化结果与刷新错误；已经提交的操作保留成功结果，刷新异常单独进入诊断日志 |
| 中 | 导入仅含标题的模板后，模板面板访问不存在的 `subtasks.length`；无标题模板被接受 | 导入时验证标题，规范化缺省子任务；面板兼顾已有最小模板 |
| 中 | 应用写作模板丢失学术类型；保存自定义模板丢失标签、类型和重复规则 | 保存并应用这些字段，子任务重新生成 ID |
| 中 | 导入带引号的任务 ID 后，添加子任务或跳转任务会生成无效 CSS 选择器 | 使用元素的 `dataset.taskId` 精确匹配 |
| 中 | `__proto__`、`constructor`、`toString` 分类名破坏统计；无效优先级影响计数 | 分类采用无原型字典，优先级与分类图标使用自身属性检查 |
| 中 | 设置页标签失败没有可见提示，重复回车可能重复创建；复制、导出、窗口切换等异步失败未捕获 | 增加忙碌状态、草稿保留、页面状态提示及持久诊断；清空仅在真实成功时报告成功，并保留确认步骤 |
| 中 | 设置写入失败后，原生偏好与数据文件不一致，控件仍显示新值 | 设置按队列提交，失败时恢复原偏好及控件，并展示原因 |
| 中 | 恢复默认设置调用已初始化的 `init()`，被保护条件拦截；逐项写入会产生大量独立提交 | 默认设置一次提交，成功后重绘控件；失败时回滚，重复点击被拦截 |
| 中 | 关闭欢迎提示与 ItemPane 设置没有对应生效点；工作区新建任务不读取默认学术类型 | 接入对应逻辑；ItemPane 开关明确标注重启生效 |
| 低 | 设置页多个表单没有显式关联标签；未实现的选项仍可操作 | 补充表单 ID 与标签关联，标注并禁用未接入的选项 |

## 尚未实现或尚未验证的部分

### 功能与设置

以下 10 个偏好在检查基线中没有运行时消费点，v11.0.3 已标注并禁用，未实现其承诺的可配置行为：

| 偏好 | 当前实际边界 |
| --- | --- |
| `pomodoroFocus`、`pomodoroShortBreak`、`pomodoroLongBreak` | 当前提供任务计时；没有番茄钟专注倒计时与长短休息周期 |
| `autoArchiveDays` | 没有按天数执行的归档流程 |
| `subwindowCompactMode` | 窗口已有布局逻辑；该开关没有接入布局控制 |
| `locateOnTaskClick` | 已有文献定位操作；该开关没有控制点击行为 |
| `dragDropFromLibrary` | 该偏好未控制文献拖入行为，不能据此承诺可配置的文献拖入功能 |
| `academicPresets` | 已有学术模板；该开关没有控制模板启用状态 |
| `pdfReaderJumpPage` | 已有页码跳转代码；该开关没有控制是否跳转 |
| `enableSound` | Zotero 通知走原生通知路径；该开关未控制声音，不能承诺插件专属声音设置生效 |

README 中“内置番茄钟”已更正为“任务计时”。任务主弹窗和 ItemPane 的默认优先级覆盖范围仍需统一；目前原生 `defaultPriority` 消费点位于 ItemPane。

多窗口同时修改同一字段仍采用最后提交值；本轮保护的是各窗口没有实际修改的字段。子任务整体列表等复合字段也遵循此规则，尚无冲突比较或选择界面。
