# Todolist for Zotero v11.2.0

## 更贴近 Zotero 的研读工作流

- **多选批量加入**：选中多篇文献后，在条目右键菜单点击“批量加入研读待办”。自动关联个人库／群组库，跳过已有未完成研读待办的文献。子附件按父文献合并；去重在原子保存队列内执行，连续操作不会覆盖其他窗口新增的任务。
- **侧边栏直接操作**：每项任务提供“编辑”和“改期”。改期可选今天、延后三天、延后一周；未设置或已逾期时从今天计算，其余从当前截止日期计算。保留具体时间、子任务、提醒设置，并重新启用通知。
- **批注双向定位**：PDF 批注右键菜单增加“加入研读待办”，选中文字弹窗也可快速记录待办。保存的批注任务保留批注 Key、来源 PDF Key、页码和摘录；列表、编辑窗口、侧边栏及同步子笔记可返回原批注。批注已删除时回退到记录的原 PDF 页码，不会误打开同篇文献的另一个 PDF。
- **学科研读模板**：通用、理论、实验、综述、算法与复现五类清单。侧边栏、编辑窗口和模板库共用同一份步骤定义。默认采用通用清单；设置中可更改默认模板。
- **统一默认截止日期**：侧边栏、批量加入、条目创建、阅读器创建、精读清单和研读模板默认一周后截止。设置可选 3／7／14／30 天。
- **原生外观与关联维护**：新增“跟随 Zotero 原生外观”，新安装及恢复默认设置采用此选项，已有明确主题选择保留。原生侧栏使用 Zotero 语义颜色与可键盘操作的按钮。通过 Zotero Notifier 更新文献标题、作者、年份、期刊及回收站／删除状态；保留任务和用户手写标题。

## 实现与验证

- 共享规则位于 `chrome/content/js/literatureWorkflow.js`，Gecko 启动和两个任务窗口均加载；不新增依赖。
- Reader 使用 `open(itemID, location)`，批注通过 `location.annotationID` 定位。Reader 事件与 Notifier 监听在关闭插件时注销。
- 修改继续使用增量持久化队列；保存失败可重试，文献联动失败不会回滚已保存任务。
- 108 项自动化回归通过，覆盖批量原子性、并发改期、学科模板、批注锚点、首次保存及元数据更新时的手写标题保护、主题事件与监听清理。
- 浏览器测试页实际操作验证了理论研读清单生成、选择保持与截止日期延后三天；360px 视口下无横向溢出。截图保存在本地 `artifacts/zotero-workflow-sidebar-360.png`。

真实 Zotero 桌面安装、菜单挂载、阅读器弹窗与定位仍需实机验收；自动化测试和浏览器测试页使用测试数据，不代表桌面验收。
