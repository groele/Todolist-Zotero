# Todolist for Zotero v11.0.0

This major release continues the Zotero 10+ line and adds a faster workflow in the Zotero Item Pane.

## Highlights

- Keeps the “学术待办” section expandable through Zotero's native Item Pane controls.
- Places quick task creation at the top of the expanded section, with Enter and button submission.
- Shows task count and completion progress while collapsed; empty sections indicate that quick creation is available after expanding.
- Adds accessible control names and prevents duplicate saves while persistence is in progress.
- Preserves entered text after a failed save so the user can retry.

## Compatibility

- Requires Zotero 10.0.0 or newer.
- Existing task data requires no migration.
