# Todolist for Zotero v1.0.5

This release hardens task lifecycle handling and reminder scheduling across Zotero windows.

## Highlights

- Prevents stale task mutations from resurrecting tasks after clear or replace operations.
- Adds cross-window reminder leases so the same reminder is not delivered twice.
- Releases a reminder lease after failed delivery so the notification can be retried.
- Re-arms notifications when reminder settings are edited.
- Unifies scheduler startup, checks, and shutdown behind one lifecycle.
- Adds regression coverage for cross-window lifecycle races and reminder delivery.
