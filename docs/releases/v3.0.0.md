# Todolist for Zotero v3.0.0

This major release requires Zotero 10.0.0 or newer. Zotero 7–9 are no longer supported.

## Highlights

- Adds an expandable desktop navigation rail. Its width and labels toggle from a dedicated button, and the preference is saved across restarts and synced windows.
- Retains the compact mobile drawer, with Escape-to-close and accessible expanded-state announcements.
- Adds rollback and user feedback if saving the sidebar layout preference fails.
- Makes the Zotero 10 minimum explicit in the plugin manifest and update feed; the package builder rejects mismatched compatibility metadata.
- Existing task and settings data need no migration.

## Validation

- `npm test`: 50 regression tests passed.
- `npm run build`: ZIP XPI integrity and manifest/update-feed consistency verified.
