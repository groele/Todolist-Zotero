# Todolist for Zotero v1.0.4

Released: 2026-10-07

## Fixed

- Preserve concurrent task changes when creating collection reading plans, PDF tasks, and reading milestones.
- Prevent competing timer starts and repeated stops from resetting timers or recording duplicate history.
- Validate complete backups before importing and merge against the latest committed data. Replacement restores templates, search history, and settings without resuming historical timers.
- Retire local undo entries after successful clear or replacement operations.
- Apply default view, task sorting, theme, and completed-task visibility settings, including live updates and persistence-failure recovery.
- Update linked literature tags and child notes after main-panel task changes, while preserving saved tasks if note synchronization fails.
- Keep matching item keys isolated by library in notes, progress, tags, and reading-plan detection.
- Honor child-note title, subtask, and quotation preferences; escape generated note content.
- Isolate storage observer errors from successfully committed writes.

## Validation

- All 43 regression tests pass, including 14 new integrity tests.
- Real Chromium checks cover creation, editing, timers, deletion/undo, reload persistence, sorting, and list/kanban/calendar/statistics navigation.
- Reviewed 460×760 companion and 1120×760 desktop layouts.
- ZIP integrity and packaged-source equality verified for the XPI.

## Compatibility and limits

No data migration is required for existing valid task files. Imports reject malformed records and duplicate or missing task IDs instead of silently dropping records. Merge imports retain existing tasks with matching IDs; choose replacement to restore the backup's task collection.

Native Zotero installation, PDF navigation, file-picker interactions, and official cloud synchronization have not been verified with this build. Reminder scheduling still requires an open task page. Linked-note failures are logged without persistent automatic retry.

Install the attached `todolist-zotero-1.0.4.xpi` through Zotero's add-on manager.
