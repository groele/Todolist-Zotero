# Todolist for Zotero v11.1.0

## 文献研读快捷操作

- 文献右侧“学术待办”顶部增加“加入待办事项”。点击即可创建“研读：文献标题”，自动关联个人库或群组库中的当前文献，默认 7 个日历日后截止，具体时间留空。
- 已存在同名未完成研读待办时显示“已加入待办事项”和截止日期。连续点击以及多个侧边栏同时创建同一默认任务不会重复添加；完成后可以再次建立研读任务。
- 原有自定义标题快捷输入仍可使用，默认截止日期同样为一周后；优先级和继承文献标签遵循设置。
- 编辑任务时，点击关联文献标题或“跳转文献条目”，切换到 Zotero 文献库并定位对应条目。条目已删除时提供反馈。
- 从文献创建任务的编辑窗口补全群组库身份，并默认填入一周后的截止日期。

## 可靠性

- 使用 Zotero 的 `onAsyncRender` 加载侧边栏数据，并防止切换条目后的旧异步结果覆盖当前文献。
- 保存按钮防止重复提交，失败后可重试；自定义输入保存失败时保留草稿。
- 文献标签和子笔记联动沿用现有保存队列和同步设置，联动失败不会撤销已保存的任务。

## 验证

- 92 项自动化测试通过，包括连续点击、群组库隔离、父条目关联、保存失败重试、草稿保留、子笔记同步失败与旧侧边栏结果保护。
- JavaScript 语法检查、`git diff --check` 和 ZIP/XPI 完整性构建通过。
- 浏览器测试页实际点击验证了一键创建、已加入状态、截止日期，以及文献标题和快捷按钮的群组库定位请求。测试页使用测试文献和内存存储，不连接真实 Zotero 数据。
