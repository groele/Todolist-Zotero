# Todolist for Zotero v3.1.0

This release improves the Zotero Item Pane “学术待办” section for Zotero 10+.

## Highlights

- Keeps the section expandable through Zotero's native Item Pane controls.
- Moves quick task creation to the top of the expanded section, ahead of long task lists.
- Shows a task count and completion summary while the section is collapsed; empty sections advertise that quick creation is available after expanding.
- Adds accessible names for the priority selector, task input, and create button.
- Prevents duplicate saves while a new task is being written and keeps the entered title available if saving fails.

## Validation

- `npm test`: regression suite passed.
- `npm run build`: package and update-feed consistency verified.
