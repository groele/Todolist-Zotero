# Todolist for Zotero v11.0.4

Zotero 7+ native academic design overhaul, smooth fluid motion, and subtask reliability release.

## Major Changes & Improvements

### 1. Systematic Native UI Overhaul (Zotero 7+ Design System)
- **Native Color Palette**: Fully harmonized with Zotero 7's clean neutral workspaces (`#f5f6f8` / `#ffffff` / `#18181b` in dark mode).
- **Zotero Crimson Accent**: Replaced outdated green/yellow colors with authentic Zotero Crimson (`#c5282a`) for primary buttons and focus states.
- **Academic Semantic Palette**: Refined badges for paper reading, writing, experiments, submission deadlines, and peer review with modern translucent pills.
- **Desktop Typography**: Completely eradicated legacy serif fonts (Georgia/Songti) in favor of the clean system sans-serif font stack.
- **Redesigned Sidebar & Modals**: Clean collections-style navigation, fluid expand/collapse drawer, and native-feeling segmented modal dialogs.
- **Preferences Dialog Alignment**: 100% matched to Zotero 7's native Preferences dialog grid, buttons, and typography.

### 2. Fluid Desktop Motion & Micro-interactions
- **Apple & Fluent Inspired Spring Curves**: Implemented `cubic-bezier(0.16, 1, 0.3, 1)` and `cubic-bezier(0.34, 1.45, 0.64, 1)` for silky transitions.
- **View Transition Motion**: Smooth fade-and-slide entry when switching between List, Kanban, Calendar, and Stats views.
- **Card Exit Height Collapse**: When deleting tasks, cards smoothly collapse their vertical space to eliminate jarring layout jumps.
- **Snappy Checkbox Feedback**: Introduced a tactile micro-spring bounce animation upon task and subtask completion.
- **Sidebar Text Slide-in**: Synchronized smooth slide-and-fade for navigation labels during sidebar unfolding.

### 3. Stability & Bug Fixes
- **Fixed `item.querySelector(...) is null` Error**: Reconstructed modal subtask items using direct DOM creation (`document.createElement`), completely eliminating fragile `innerHTML` lookups that caused unhandled rejection errors.
- **Guarded Template Subtasks**: Added defensive optional chaining and fallbacks for custom templates without subtask arrays.
- **Form Button Safeguards**: Explicitly set `type="button"` on subtask controls to prevent accidental modal form submission.
