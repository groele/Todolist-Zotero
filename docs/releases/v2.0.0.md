# Todolist for Zotero v2.0.0

This major release improves interaction feedback, keyboard and screen-reader access, and the small-window experience while preserving the existing task data format.

## Highlights

- Makes task and subtask completion controls keyboard-operable and exposes their checked state to assistive technology.
- Adds concise live announcements for task feedback and undo actions.
- Respects reduced-motion preferences and limits entry animation to newly rendered tasks.
- Refines compact side-panel spacing and toast visibility transitions.
- Keeps plugin update discovery on the repository's Zotero branch and points the update manifest to the matching GitHub Release asset.
- Aligns plugin, package, backup, documentation, update metadata, and XPI versions at 2.0.0.

## Compatibility and data

- Existing task and settings data need no migration.
- Backup JSON remains compatible; its exported version field now reports 2.0.0.
- The update feed remains at `https://raw.githubusercontent.com/groele/Todolist-Zotero/zotero/update.json`.

## Validation

- `npm test`: 48 regression tests passed.
- `npm run build`: ZIP-based XPI integrity and manifest version verified.
- Packaged source files match the current repository contents.

Install `todolist-zotero-2.0.0.xpi` through Zotero's add-on manager. The GitHub release asset becomes available after the v2.0.0 release is published.
