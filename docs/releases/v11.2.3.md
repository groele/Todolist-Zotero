# Todolist for Zotero v11.2.3

## 修复文献侧栏控件消失

- 将中英文区块标题的 Fluent 消息改为仅设置 `.label` 和提示属性。原先的消息文本会覆盖 Zotero 原生 `collapsible-section` 的内部 DOM，导致标题、折叠箭头、正文和动作按钮消失。
- 保留原生可折叠区块和正文中的“添加到论文研读”按钮；创建关联当前文献的待办，默认一周后截止。
- 关联任务仍通过独立的“↗ Zotero”按钮定位其文献条目。
- 隔离插件正文的固有宽度，避免长文献标题撑宽原生侧栏、将跳转按钮挤出视野；日期及次要操作移至可换行的操作区。
- 增加原生控件本地化回归检查，防止消息文本再次覆盖区块和侧栏图标按钮。

## 验证

- `npm test`：112 项通过；新增回归检查在旧消息上复现失败，修复后通过。
- `npm run build`：版本、更新链接及 ZIP/XPI 内容检查通过。
- 本机 Zotero 10.0.6：真实点击“添加到论文研读”，保存当前文献关联及一周截止日期；原有 4 项任务保留，新增 1 项后重启仍为 5 项。
- 选择新增研读文献的 PDF 附件后，真实点击“↗ Zotero”，主列表切回对应的父文献条目；窄侧栏内完整显示跳转按钮，长标题以省略号收缩。
- 最终 XPI 已加载到本机；安装副本与构建产物 SHA-256 一致。
