# Todolist for Zotero v11.0.3

Zotero 10+ stability and settings audit release.

## Fixes

- Merge concurrent tag, template and search-history edits against the latest committed data.
- Submit only changed modal fields to preserve edits made in another window.
- Validate storage-message sources in the host and task pages.
- Preserve successful save/import/clear results when a later refresh fails.
- Normalize minimal imported templates and preserve academic type, tags and recurrence.
- Handle quoted imported IDs and prototype-like category names safely.
- Catch preference-page async failures, retain failed tag drafts and prevent duplicate submissions.
- Roll back failed preference changes and restore defaults in one commit with refreshed controls.
- Connect welcome, item-pane visibility and default academic type settings; improve form labels.
- Mark and disable settings with no runtime consumer. Correct the Pomodoro claim to task time tracking.

Includes the v11.0.2 fix for `firstTimeShown` and `pendingTask` startup errors.

## Validation and limits

- 82 automated tests passed; 25 JavaScript source files passed syntax checks.
- ZIP-based XPI built and checked for integrity, required files and aligned update metadata.
- A memory copy of the real task file rendered all four views without captured errors; the source file was unchanged.
- The inspected desktop still loads v11.0.1. Live Zotero startup, sidebar, PDF and note-sync workflows require verification after updating.
- Focus/break cycles and automatic archival remain unimplemented. Concurrent edits to the same field remain last-write-wins.

See [the detailed audit](https://github.com/groele/Todolist-Zotero/blob/zotero/docs/audits/v11.0.3-audit.md).
