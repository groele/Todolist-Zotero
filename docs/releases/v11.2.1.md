# Todolist for Zotero v11.2.1

## 研读按钮与文献跳转

- Zotero 文献右侧“学术待办”显示明确的“添加到论文研读”按钮；按钮使用内联原生样式，即使 Zotero 外层主题样式未加载也保持可辨识和可点击。
- 点击后创建关联当前文献的研读任务，沿用默认截止日期、优先级、去重和保存失败重试逻辑。
- 已关联任务显示“已加入论文研读”；每条关联研读任务旁提供“↗ Zotero”按钮，按文献 key 与所属库定位个人库或群组库条目。
- 任务标题仍打开待办详情；单独的条目按钮负责跳转 Zotero 文献，两个动作互不冲突。

## 兼容性

- Zotero ItemPane 使用插件注册区块的 HTML body；按钮通过区块现有任务创建和 Zotero 条目定位 API 工作。
- 本地 Zotero API 状态检测为 10.0.6 且服务正常；当前桌面自动化未暴露 Zotero 窗口，因此未完成真实窗口点击验收。
- 未更改任务数据结构；现有任务和备份无需迁移。
