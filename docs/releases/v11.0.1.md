# Todolist for Zotero v11.0.1

This patch fixes confirmed asynchronous error leaks and adds persistent error diagnostics for Zotero 10+.

## Fixes

- Catch failed quick additions, subtask additions, inline edits, batch changes, undo, drag operations and shortcut exports at their event boundaries.
- Preserve quick-add and inline-edit drafts when persistence fails, and allow retry without duplicate Enter submissions.
- Await statistics rendering when switching views. Ignore stale results and avoid accessing a closed window after an asynchronous render.
- Return the underlying initialization and note-sync errors through both direct and main-window Zotero bridges.
- Show the operation and underlying error instead of the generic partial-operation warning.

## Diagnostics

- Error diagnostics are enabled automatically on plugin startup.
- Console records include the operation, error reason and stack trace.
- The last 50 records are written atomically to `todolist-debug.json` in the Zotero data directory, separately from `todolist-data.json`.
- Records include the plugin version and time. Logging failures do not interrupt task operations.
- Existing task data requires no migration. The repository update feed points to the v11.0.1 XPI.

## Validation

- `npm test`: 62 regression tests passed, including 12 new error and lifecycle regressions.
- Actual local task data was read and rendered from a copy in four views; the source file was unchanged.
- JavaScript syntax checks, package build and ZIP integrity checks passed.
- These checks used DOM and host fixtures. The original desktop console stack was not available, so this release does not claim that the user's specific live error has been reproduced end to end.
