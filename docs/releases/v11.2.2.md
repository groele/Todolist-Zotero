# Todolist for Zotero v11.2.2

## 修复 Zotero 文献侧栏

- 修复“学术待办”侧栏图标按钮在窄栏中显示竖排文字的问题；图标保持原生 28px 按钮尺寸，悬停提示和无障碍名称仍可用。
- 将“添加到论文研读”和每条关联任务的“↗ Zotero”按钮放入同步渲染路径，避免 Zotero 未调用异步渲染时整个区块空白。
- 当前文献选择为空时，从 Zotero 主窗口的选中条目回退；待办读取失败时仍保留添加按钮并给出错误提示。

## 验证

- `npm test`：111 项通过。
- `npm run build`：XPI 包构建通过。
- 在本机 Zotero 10.0.6 中重启并加载修复包；插件处于启用状态，本地 API 返回 200，侧栏图标不再出现竖排标题文字。
