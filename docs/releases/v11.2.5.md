# Todolist for Zotero v11.2.5

## 图标与视觉体验升级

- 全面升级插件图标为 v11.2.5 专属定制「无边界全彩破界套件 (Unbounded Flow / Style 7)」：
  - 主图标设计采用极简无边界悬浮语言，融合科研文献胶囊流（#3B82F6 / #0EA5E9）与破界动态对勾（#2563EB -> #06B6D4 -> #10B981）及高优星芒标记。
  - 同步更新插件运行所需全尺寸栅格 PNG（16、32、48、64、96、128、256、512 像素）与自适应 SVG 矢量图标（`todolist.svg`、`icon.svg` 及无阴影平滑版）。
  - 在扩展包根目录注入 `icon.png` (48x48) 与 `icon@2x.png` (96x96)，并在 `manifest.json` 中配置标准 `icons` 映射，完美适配 Zotero 10+ 插件管理器 (about:addons) 与高分屏视网膜渲染。
  - 在 `scripts/apply_icon.py` 中收录 Style 7 (Unbounded Flow)，支持一键无损切换与构建。
